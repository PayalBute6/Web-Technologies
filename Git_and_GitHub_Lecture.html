Git & GitHub

2. What is Git?

Simple definition

Git is a Version Control System used to track changes in source code.

Git was created by Linus Torvalds in 2005 and is distributed, meaning each developer can have a complete copy of the project's history.

Think of Git as:

Your Computer
      ↓
     Git
      ↓
Tracks your project changes

For example:

MyProject/
   ├── Login.java
   ├── Student.java
   └── Main.java

Git watches these files and remembers their changes.

3. What is GitHub?

Git ≠ GitHub

Think of it like this:

Git
 ↓
Tool used to track changes

GitHub
 ↓
Online platform where Git repositories can be stored/shared

Very simple example

Suppose you have:

Laptop
   ↓
My Project
   ↓
Git

You want to put your project online:

Laptop
   ↓
Git
   ↓
GitHub
   ↓
Online Repository

Git = Version control
GitHub = Online hosting + collaboration

4. Git Commands

STEP 0 — Install & Check Git

Windows: Download from the official website or install using Winget:

winget install --id Git.Git -e --source winget

Linux (Ubuntu/Debian): Install using apt:

sudo apt update
sudo apt install git

After installing Git, open Git Bash (on Windows) or your terminal.

Check Git:

git --version

STEP 1 — Configure Git

Do this only once on your computer.

Set your name

git config --global user.name "Your Name"

Set your email

git config --global user.email "your@email.com"

STEP 2 — Start Git in a Project

Open the terminal inside your project folder and run:

git init

Now Git starts tracking the project files.

STEP 3 — Check Status

Always use this command to see what files are modified:

git status

STEP 4 — Add Files (Stage)

To tell Git to prepare all modified files for saving:

git add .

STEP 5 — Commit (Save)

Create a checkpoint (save) with a descriptive message:

git commit -m "Initial commit"
ADD = Prepare
COMMIT = Save

STEP 6 — Connect & Push to GitHub

Connect your local Git to a new GitHub repository:

git remote add origin YOUR_GITHUB_URL

Ensure you are on the main branch:

git branch -M main

Send your code to GitHub:

git push -u origin main

🎯 The Daily Workflow

Once everything is set up, you will use this cycle every day:

git status
git add .
git commit -m "Update message"
git push

5. Branching & Merging

Branches allow you to work on new features or experiments without affecting the main project code.

1. See all branches

To list all branches in your repository (the current branch has an asterisk * next to it): 

git branch

2. Create a new branch

To create a new branch named feature-login:

git branch feature-login

3. Switch to a branch

To move to the branch you just created:

git switch feature-login

(Note: older versions of Git used git checkout feature-login)

4. Create and Switch in one command (Shortcut)

To create a new branch and immediately switch to it:

git switch -c feature-login

Merging Branches

Once you finish working on your new branch, you usually want to merge those changes back into the main branch.

Step 1: Switch back to the main branch:

git switch main

Step 2: Merge the feature branch into main:

git merge feature-login

5. Delete a Branch

Once you have merged a branch and no longer need it, you can delete it safely:

git branch -d feature-login
